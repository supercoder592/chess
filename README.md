# chess — 西洋棋練習場

這個 repo 是用 [D:\chess](../chess) 那個自我對弈訓練出來的 AI，
陪我練棋、記錄每一局、逐步加強對手棋力的地方。

## 怎麼運作

1. **測棋力**：第一次玩的時候用固定強度的 AI，看勝率估出我目前大概的棋力
2. **逐步加壓**：AI 會根據最近 5 局戰績自動調整難度，目標讓我維持接近五五波
   的勝率，太輕鬆就加強、太難就放水
3. **賽後講評**：每一局結束後，AI 用自己訓練出的價值網路，指出這局裡評估
   落差最大的幾步（對我最有利/最不利），純粹是網路自己的判斷，
   沒有任何人寫的棋理規則或開局定式庫
4. **全部記錄**：每一局的棋譜（PGN）和講評都會自動 commit 上來

## 目錄

- `games/` — 每一局的 PGN 棋譜 + 對應的講評（`*_commentary.md`）
- `RATING.md` — 棋力進度總表，含每局戰績、難度階、棋力變化

## AI 是誰

跟這個 repo 對弈的 AI 完全靠自我對弈學會下棋（AlphaZero 式訓練），
沒有人告訴它任何開局或戰術知識 —— 走的每一步、給的每一句講評，
都是它自己從幾千局自我對弈裡學出來的。
